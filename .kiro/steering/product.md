# Product Steering

- Build an incident investigation system, not a generic chatbot.
- The model may propose restricted hypotheses; trusted code verifies them.
- Reports recommend diagnostics only and never execute remediation.
- Preserve `UNKNOWN` when evidence is missing, stale, failed, or incompatible.
- Every material accepted claim must link to authorized evidence and a verifier trace.
- Scope additions require a user problem, acceptance criteria, and measured justification.
